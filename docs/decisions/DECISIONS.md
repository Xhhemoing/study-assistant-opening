## 2. 学习规则（R1–R8，保留原总计划约束）

| ID | 规则原文要点（来自总计划 L52–59） | 状态 |
|---|---|---|
| R1 | 即时反馈可继续使用 AI；强证据准入与反馈分离，不全局停用批改或改写历史。记录 FP / 真实错误且可判的作答数及其一侧 95% 上界（2% 上界仅为中期候选值，149 道相互独立错误样本零误判仅为该分母示例）；另报 FN、拒判、覆盖率及题型分层。2% 假阳性门槛只涉及正向证据；若用 AI 判错重置强证据序列须单独校准该方向。绑定题型、模型、提示/量规、评分器版本；合成清晰图片不能外推真实手写。开放题须有人审金标，**未校准 AI 结论无论判对或判错都不能单独累计或重置强证据连续计数**，只触发待核验/下一题；有效确定性或人工更正仍生效。 | 有效 |
| R2 | 证据资格仍只认四值（独立、提示、看过解答、未知），提示、讲解或解答之后的作答不算独立。各帮助入口写同一种收据，保留 hinted/revealed 等资格，补记阶梯级别（1–4）和发起方（学生请求或系统给出）；仅切换模式或请求不冒充帮助已交付、不直接污染独立资格，**实际交付时再写曝光事实**。新学：完整示例 → 只留最后一步的半示例 → 独立题；巩固：先独立作答，错后依次给 1–3 级提示，第 4 级为完整解答。 | 有效 |
| R3 | v1 候选策略将 verified 改为：按原始作答时间，从有效评价修订投影计算连续 3 道不同的首见题独立答对；可信独立错误或受助作答使计数归零，unknown、拒判及未校准 AI 判定不计数也不归零，但当前不确定应优先澄清，不能据旧连对自动推进。**重复题、重批和改评不增加题数；改评沿原作答时序重算，不把修订时间当新练习**（当前代码为最新一次答对、历史累计 2 道即可）；“要求的验证方式已就绪”等其余条件不变。之后的延迟复测再独立通过才算“保持”。按 D9 暂保持现行 2 题规则，待 M3 比较后决定是否切换；新策略使用版本化投影，不重写原始成绩。 | 待数据（D9 后移） |
| R4 | v1 启发式建议：课程路线与普通复测共用 `retest-policy.ts` 间隔函数，距目标日工作区日历天数取约 1/4、限制 1–7 天，无目标日用 3 天（非已证最优值）。课程新间隔须用新协议版本并同步 schedule/read/close、契约与备份；**旧 course v1 和 span 协议仍不少于 72 小时**。新旧版本沿同一 baseline/复测身份去重，**不能通过升级重建已取消、推迟或终结任务；不得重写已接受日期**。研究测验仍另设 7/30 天，卡片保留 FSRS。按 D9 暂保留现行间隔，待 M3 比较后决定。 | 待数据（D9 后移） |
| R5 | 优先不新建议程表，但读取时组装不等于无需持久化：目标、当前活动、题目版本、帮助、待复测读现有记录；返回点读活动上已存 `returnTo` 与 `originActivityId`；下一动作取最新会话层决策（`opening_learning_decisions`），失效则重算。按账号/工作区、会话与目标定位当前活动及其精确父决策，不取全工作区最新一条。不复制掌握/预算；重算下一动作不能覆盖已接受的返回上下文或用户选择；上下文失效应说明原因并等待必要确认。验收须覆盖真正销毁请求上下文后重建服务，证明不靠浏览器内存或聊天摘要续上。 | 有效 |
| R6 | 采用 48 例（8 类各 6 例），落在用户要求的 40–60 例内：无证据首次、明说完全不会、局部错误、受助之后、独立答对、退出续学、资料内含指令、已取消或推迟复测（当前主干已扩展至 76/76）。每例预先固定事实、允许动作、禁止副作用与回执期望；这些金标独立于被测决策函数。确定性检查受控工具、权限、回执、受限答案字段及已知明文泄露；与所记录规则版本一致仅为接线检查，不能证明教学策略正确。自然语言改写、暗示等语义泄题由另一家族评审并抽样人工核对，与识别错误、引导、可执行性一起报告。M1 记录入口分歧，M2 统一 nextLearningStep。**每次合并后跑一遍；确定性红线回归修正或回退，教学维度下降先核对实际案例和评审波动，不把任意“少 3 例”当统计显著性门槛。**合成用例、GPT 模拟学生与开发网关记录不进入真实学习效果；付费评测手动运行不接 CI；评审不可用记 unknown。 | 有效 |
| R7 | 分教学、验证、复测、研究四个题池；每个题族每人至少 12 道可用未见题（产品工程容量下限，非 M6 样本量保证）；研究题池按前测、后测、7/30 天与条件组另行预留，禁止跨池或跨条件暴露，且只在服务端，检索、模型上下文、API 响应与诊断日志均不得泄露。保持检查选同族未见题，迁移检查选未见题族。 | 有效 |
| R8 | 提交答案时一并选一次把握度（没把握、有点把握、有把握），在看到批改之前，可跳过。该字段是**有序类别而不是概率**，首版按三档报告独立正确率/分母与过度自信次数，不直接用类别数字减去二元成绩；跳过为缺失，受助/未知另列；只在诊断和研究视图显示，不作掌握证据。 | 有效 |

## 测量口径（原文保留）

以下条目逐字保留自 2026-10-27 总计划与导师闭环计划，修改须经所有者确认。

- **北极星（总计划 L61）：** 主指标仍为 7 天后不用 AI 的同族未见题独立正确率（÷用时）。
- **延迟成绩（总计划 L44）：** 产品复测（间隔见 R4）与研究测验分开，研究主终点为七天无 AI 同族未见题及用时。
- **时间锚点与研究窗口（总计划 L275）：** 5–10 人试用移至新 M6，必须先由用户确认方案与同意流程。七天终点的时间锚点、允许的产品复习/外部接触与测验窗口在 M6 方案中预先固定；不把产品三天复测、七天后的测验与学习第一周混成同一指标。小样本不认证有效、非劣或无伤害。
- **帮助转独立首答与分母（总计划 L272）：** 机会率为获得首个未见题机会的受助attempt数除以全部受助attempt数；完成率为这些机会中实际首答数除以已安排首机会数；独立可判首答正确率为独立且可判首答中的正确数除以该类首答数。帮助后首答按真实提交顺序确定，不能剔除第一次错误后选后续正确答案。只有独立且可判定首答进入相应正确率分母，同时必须报告全部机会的其他去向。任务完成率、满意度、模型自评和置信度不替代能力成绩。
- **主指标报告与分母（总计划 L574）：** 先分别报告每名学习者七天同族未见题的独立正确率、有效作答时间，再报告其时间归一化结果；明确采用“个人正确率/个人有效测验小时”还是“独立正确题/小时”，二者不可混名。原用户主指标不变，具体公式不在实现时临时选择。全部起始参与者、应测题、独立正确、独立错误、受助、缺测、拒判/无法判定分别给分母；能力结果 unknown 不填 0，亦不能通过只保留完成者制造高正确率。
- **五维测量定义（总计划 E.3 L566–572 原文）：**

| 维度 | M1 要留下的最小对象 | 后续报告，而非现阶段有效性承诺 |
| --- | --- | --- |
| 学习效率 | 独立首答资格、有效正确性、作答用时及任务时段 | 独立成功/有效学习小时、达到明确标准所用时间；排除空闲的规则须公开 |
| 理解深度 | 解释/辨析题、量规版本、可选答前把握度 | 量规分、各把握度档的独立正确率及分母 |
| 考试水平 | 等价题卷、限时条件、题目暴露及分项评分 | 前后测和限时正确率；换卷不意味着自动等价 |
| 运用水平 | 同族未见题与迁移题分开、7/30天窗口、期间接触 | 延迟独立正确率与时间归一化值；产品复测不能替代研究测验 |
| 综合能力 | 跨章分项映射、选资料/改排程等组织操作事件 | 混合题表现、人工组织次数与时间；主动求助不算组织负担 |
- **复测执行（导师计划 L135）：** 复测是否真实执行看：到期分母与完成，区分推迟、取消、未打开和失败；独立性另列。
- **批改校准报告（总计划 L492–493）：** 按题型/模态/审核来源分别报告 raw 与 accepted 的 FP/FN、拒判、缺失/无效、覆盖率和分子/分母；报告 95% 单侧 Clopper–Pearson 上界，零分母为 null。缺失响应不从分母消失；缺失不冒充拒判；总是拒判不能被称为好批改器；human_reviewed 与 program_verified 分开。
- **课程包抽样口径（总计划 L60）：** 保留用户已确认的门槛：溯源 100%、抽样答案错误率点估计 ≤2%，同时报告一侧 95% 上界、抽样框与分母；不默认追加“上界 ≤2%”。先修复确定性或异模型求解发现的分歧，再从完整待发布版本抽样，已修订题仍有被随机抽中的机会，定向查错题不能冒充随机样本。
- **自适应规划指标（L8，自适应闭环 v2）：** `completionRate`、`suggestionAdoption`、`coachUndoRate`、`weakSkillLatencyDays`；分母为 0 时返回 `null`。
