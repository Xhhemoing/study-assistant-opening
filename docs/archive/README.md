# 文档归档

- 本目录保存已失效或已完成的历史快照（旧计划、阶段总结、评审记录与发布证据），不代表项目当前状态；当前状态以 [docs/STATUS.md](../STATUS.md) 为准，活跃文档索引见 [docs/README.md](../README.md)。
- 目录按归档前相对路径组织：`docs/archive/plans/*` 对应原 `docs/plans/*`，`docs/archive/operations/*` 对应原 `docs/operations/*`，根目录阶段性报告保存在 `docs/archive/`。
- 所有含代码/CI 外部引用的基准文档与执行规范保留在原路径（`docs/plans/`、`docs/superpowers/`、`docs/quality/`、`docs/operations/`），不迁入归档目录。
