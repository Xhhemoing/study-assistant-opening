## 0. 总原则

1. **让每项能力都能被真人体验，再取舍**（D14）：不删能力；没有入口的能力必须接线；内部工具（仿真器、GEPA 编译器、漂移哨兵、三账本）归开发运营层。
2. **同一件事只做一套入口**：合并重复入口，不合并掉能力。
3. **部署分段、每段所有者批准**（D1）。
4. **现有门禁不放宽**：L/H/U 分级、异家族双审、精确 head CI、唯一集成者、U 级部署审批、浏览器验收归所有者。
5. **交付卡必须写明**：从哪个入口进入、真人做什么、能看到什么结果、谁已体验；无入口标“已实现，待接入”，不算交付。
6. **部署落后即冻结**：主干领先线上 >1 个迁移或 >14 天未部署 → 只做部署准备、修复与验收问题。

## 5. 平台能力

### 5.1 跨入口回归（R0，先于开关开启）
一条集成测试：V2 拍照作答 → 领取提示 → 自核 → 撤回 → 从“今日”与课程路线继续。断言：同一课程要求、同一有效作答版本下独立已验证数为 0；撤回后重算复测且保留已发生曝光；两入口传给共享 builder 的事实一致；图解开关只改变展示。

### 5.2 反馈与使用漏斗（R0）
- 壳层“反馈此页”抽屉：一句话 + 自动附带 pathname、开关摘要、最近错误码；落库并进入使用反馈队列（H，含迁移）。
- 只读使用漏斗周报：基于 `opening_jobs`、`opening_turns`、学习事件统计每项能力的触发次数与失败率（L/H 视是否新增表）。
- 远端 CI 扩面：三入口可达、卡带工坊、多稿写作、知识地图、`/try` 的冒烟与无障碍检查（L）。

### 5.3 移动端（R1）
- 最小 PWA：`app/manifest.ts` + 图标 + `viewportFit: "cover"`；**只缓存图标与字体，不缓存 HTML 与 API**（避免 `buildConfigDigest` 失配导致能力全关）。
- 录音（W-7）、扫码传草稿（W-8）、小屏会话（A-7）。

### 5.4 国际化（R1 起步，R2 完成）
- 不使用 URL 语言前缀（会击穿重定向安全校验）；采用 Cookie + `workspace_preferences.locale` 驱动的无前缀字典方案。
- R1：AI 提示词、反馈、周报跟随 locale 与资料语言输出英文；`<html lang>` 动态化；BlockNote 语言包与日期格式跟随 locale。
- R2：主壳层、认证与上手、三入口主干界面双语；低频设置 R2–R3 渐进完成。

### 5.5 双区域（R1 搭建海外部署，R2 前就绪）
- 同一版本两套部署：大陆与海外各自独立的 Web、Worker、PostgreSQL、Redis、对象存储、日志与备份；账户注册时固定归属区（新增 region 字段，H）。
- 模型目录按部署配置：大陆用已备案模型并核实推理范围；海外按目标国与供应商条款选用。所有调用（文本、嵌入、图片、语音、失败回退）走区内端点。
- 不跨区同步个人数据；导出/删除对两区一致。

### 5.6 未成年人（R1，H 级迁移）
- 注册收集年龄段（<13 / 13–14 / 14–17 / 18+，不存精确生日）与条款同意版本；
- 大陆未满 14、海外未满 13（及欧盟本国门槛以下）进入 `pending_guardian_consent`；
- 未满 18 默认关闭去标识数据集入池与公开分享卡。

### 5.7 免费额度与成本（R2）
- 复用工作区每日预算预留作为“每账号每日额度”（唯一索引保证每账号一个工作区）；区域内独立计算并对外说明适用范围；
- 核清所有收费入口均经预留；成本看板按区域输出 P50/P95；
- 配额模式由 unlimited 切换为有限额须所有者批准（生产配置）。

### 5.8 合规工程项（R0 准备，R2 前完成）
AI 生成内容显式标识（界面）与隐式标识（下载文件元数据）；隐私政策与用户协议双版本；删除级联与删除报告；处理商与数据流清单。法律定性由所有者确认（见 [OVERVIEW.md](OVERVIEW.md#需要你本人做的事)）。
