## 用户浏览器验收（待完成）

入口：`/opening/today`；课程与材料入口：`/opening/courses`；规划设置入口：`/opening/settings`。

数据前提：已保存作息，有至少 25 分钟的连续可用时段；课程有当前版本可用材料；完成一次可核对的独立错误作答。尚无作答或只有未核对结果时，不应被当作已确认答错。

1. 副驾驶档查看“下一项 + 原因”，展开安排和依据；草案预览阶段任务列表不增加。
2. 取消一条建议、确认；仅勾选且排入时段的建议成为任务。放不下项标明原因并不可勾选。重复点击或同选择重试不增加任务。接受的卡片建议应进入卡片复习，关闭教学工作区也能使用，不创建空主讲。
3. 在另一处完成/修改任务、撤销材料、新增冲突课表或缩短可用窗口后直接确认旧草案；应显示具体原因，不出现半套新任务。刷新后不可用建议消失；过期草案重新安排到未来可用时间；移除规划设置后不再展示旧草案。
4. 新作答改变建议时，仍能执行的草案保持稳定，出现“有新建议”；点击才刷新。当天已完成/跳过的同项不重复推荐。
5. 从已接受的建议点“开始此项”：任务的真实课程、技能与材料进入主讲。未知水平先诊断；核对答错针对那题与原答案；提示后答对减少辅助练习；独立证据支持迁移检查。再次作答的技能默认值应沿用教学重点/当前大纲；手工改名或清空后，异步读取不覆盖输入。真实生成质量由用户抽检。
6. 手工档不生成建议；关闭开关后，既有规则草案入口仍可用。已创建任务与学习事实保留。
7. R9b 使用一份多段音视频，普通可恢复失败后应出现“重新解析”；前面成功的段应复用，账本不重复结算。供应商结果未知时材料应结束“解析中”并说明不能重发，不因换任务 ID 再次收费。此项可能产生正常模型费用，按用户自己的模型预算执行。
