2. 合入两个 PR 后，确认主干 CI。保留 #46 的旧文档讨论；本批只移植其 G1 去重实现，不整体合入旧方案。
3. 在 Hermes 核实实际运行 SHA、数据库迁移记录和当前配置。旧 STATUS 中的 `8b500e6` 不是现场证明；按现有运维流程备份，再应用主干缺失的既有迁移。
4. 以 `OPENING_ADAPTIVE_PLANNING=0` 部署 web 和 worker。检查登录、既有 Today/任务、材料解析与 worker 健康。教学编译沿用已经批准的模型与开关配置。
5. 由用户选择自用验收时间，再将 web 的 `OPENING_ADAPTIVE_PLANNING` 开为 1。教学质量检查需要已配置的可用模型；规则草案与学习事实不需要模型调用。
6. 将现场 SHA、迁移状态、开关状态、验收结果记回 STATUS。Agent 未执行 Hermes 操作或浏览器验收。

## 用户浏览器验收（待完成）

入口：`/opening/today`；课程与材料入口：`/opening/courses`；规划设置入口：`/opening/settings`。

数据前提：已保存作息，有至少 25 分钟的连续可用时段；课程有当前版本可用材料；完成一次可核对的独立错误作答。尚无作答或只有未核对结果时，不应被当作已确认答错。

1. 副驾驶档查看“下一项 + 原因”，展开安排和依据；草案预览阶段任务列表不增加。
2. 取消一条建议、确认；仅勾选且排入时段的建议成为任务。放不下项标明原因并不可勾选。重复点击或同选择重试不增加任务。
3. 在另一处完成/修改任务，或撤销材料后确认旧草案；应显示具体原因，不出现半套新任务。刷新后不可用建议消失；过期草案重新安排到未来可用时间。
4. 新作答改变建议时，仍能执行的草案保持稳定，出现“有新建议”；点击才刷新。当天已完成/跳过的同项不重复推荐。
5. 从已接受的建议点“开始此项”：任务的真实课程、技能与材料进入主讲。未知水平先诊断；核对答错针对那题与原答案；提示后答对减少辅助练习；独立证据支持迁移检查。真实生成质量由用户抽检。
6. 手工档不生成建议；关闭开关后，既有规则草案入口仍可用。已创建任务与学习事实保留。
7. R9b 使用一份多段音视频，在后段失败后点重新解析；前面成功的段应复用，账本不重复结算。供应商结果未知时应明确失败，不能因换任务 ID 再次收费。此项可能产生正常模型费用，按用户自己的模型预算执行。

## 回滚

先关闭 `OPENING_ADAPTIVE_PLANNING`，保留已有任务与学习事实。需要回滚部署时使用上一个已验证构建；不回退既有迁移、不清空转写回执或预算账本。模型故障沿用现有失败/待核对路径，不能假称内容已生成。
