## 使用规则

- 新增研究先复制 [研究记录模板](templates/research-note.md)，再在本索引登记。
- 一个记录必须指向具体产品流程、领域对象、代码边界或计划任务。
- `proposed` 只能表示“建议批准”，不能被当成正式规格。
- 提升到正式文档后改为 `promoted`，并补充目标链接。
- 研究被推翻时使用 `rejected` 或 `superseded`，保留原因和替代链接。
