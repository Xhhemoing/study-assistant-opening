## 分析后采用的修正

- 四类学习状态是学生可理解的证据摘要，不替代长期掌握估计。一级至三级提示后答对都属于依赖提示；看过完整示范优先进入待复测。零提示也必须同时满足有效作答、未见解答等现有资格要求，才可称本次独立完成。UX3 实施时沿用服务端证据，不能在浏览器自行认证。
- 复习统一入口保留不同调度与评分语义。记忆卡自评不能转成独立答对。当前 `/opening/review` 是 AI 建议审核入口，UX4 合并前必须先迁移该入口并保持旧链接与队列上下文。
- 旧助理、冲刺和卡片路由的迁移必须保留已支持的课程、会话、活动、资料页码和选段；缺少课程的旧冲刺入口提供选择，不自动猜测课程。
- 保留阅读偏好。英文原题、中文题意和英文数学步骤均可用；用户已明确需要先读中文题意，不能强制其默认收起。
- 文案不能把未知资格统一说成“再做一次就能确认”，也不能在异步评分完成前显示正确与独立完成。即时接收反馈与最终判分分别验收。
- 中途会话过期不能强制离开学习页面：现有作答和提问草稿在浏览器拒绝存储时会退回本页内存，硬跳登录会丢失输入。本次对明确的 `UNAUTHENTICATED` 显示重新登录入口，原页面保持挂载但暂时禁止交互，受管请求暂停；新标签登录后验证原 `user.id` 与 `workspaceId` 才可恢复，避免旧草稿写入另一账户。首次未登录访问仍按原鉴权入口跳转。供应商鉴权错误和非 JSON 401 不推断为用户会话失效。返回地址限定站内。此项有意修正文档“一律跳登录”。
- 深色 token 要补齐错误色与学科对象色；附件的深色背景上原错误色对比不足。浅色装饰线不能直接作为唯一输入边界。
- 关闭浮层时立即取消交互与辅助技术可见性，退出动画不延长可聚焦时间。快捷键不得抢占输入框、公式编辑器或中文输入法。
- `details` 和 `role=status` 数量仅作整理参考，不代替语义正确性。渲染次数阈值只用于受控回归；核心检查是更新最终稳定、无重复请求与草稿丢失。

## 验证与验收分工

实现时运行最接近修改的单元回归、Web 类型检查和修改文件 lint。维护现有 CI 中的软导航检测，记录页面文档请求与页面错误；不降低既有 CI 门禁。仅 CSS 合并需验证真实 Tailwind 编译，不能用字符串快照代替。

根目录与 Web 的 `AGENTS.md` 约定浏览器验收由用户执行。浏览器 E2E、截图、深浅色与窄屏视觉在本轮标记待验收，现有 CI 浏览器检查保留。未验证生产部署、真实学习收益或 INP；附件原型的 axe 结果不作为项目的通过证据。

UX0 用户验收：登录后打开 `/opening/today`，从有学习断点的课程返回今日；连续切换今日、课程和资料，检查无卡顿或更新深度错误，浏览器前进后退仍可用。打开移动端更多菜单切换页面后菜单应关闭。会话失效后应看到重新登录提示且原页输入仍在；在新标签登录后回到原页重试，不能自动重发未确认的写入。首次未登录访问检查安全返回地址。检查原工作区与 opening 页面均可读。

## 本轮实现范围

ResumeCard 已稳定默认数组与 API 实例，去掉未发送草稿镜像 effect；同步只确认对应版本的实际草稿，并要求服务端回读一致。保存期间的新编辑、跨版本草稿、冲突和活动切换后的迟到响应均有回归覆盖。

主导航恢复 Next Link，壳层按路由更新 AI 建议计数，读取失败不保留过时数字。现有 E2E 增加桌面与 390px 的文档请求、timeOrigin、前进后退、页面内容与激活项检查；这些浏览器用例尚未运行。

会话恢复覆盖 OpeningApi、learning-client、cards-client，含其使用同一 transport 的教练、建议与上传方法；其他裸 fetch 尚未全部迁移，不能称全站 401 已收口。过期期间保留组件与草稿、禁用交互，显式复验同账号和工作区后才恢复受管请求，不自动重放写入。恢复对话框使用原生模态顶层，避免被已有学习或资料弹窗遮断；实际键盘与嵌套模态仍待浏览器验收。

Tailwind 成为统一 token 定义来源，旧语义名称保留兼容映射；globals 的旧变量改为别名且不重新导入。已补深色错误和图示色、修正次要文字对背景的对比，并提供减少动效规则。这里只完成主题基础，全站颜色迁移、主题设置和浏览器视觉仍属 UX1/UX5。
