## 共同规则与迁移分配

1. 一个服务端 resolver 校验 owner/workspace/course/attempt/activity/block/item/source/chunk/KC 版本；无法解析旧版本明确未知或冲突，不静默改为最新。
2. generated、released、acknowledged 分列；释放前使用与提交相同的工作区历史锁，按服务端顺序解释独立性；release key 幂等，ack 不重复记帮助。
3. 父预算满足 settled + pending reservations + next conservative upper bound ≤ parent cap；重试和 fallback 共父 ID，计费未知保持预留，无法估计上界时不假装有保证。
4. Decision 保存层级、父 ID、状态/目标/意图/策略版本、候选与排除原因、选中动作、来源、失效条件。历史解释读取历史记录。
5. 四证据视角可同时成立；未检查不是能力差或已遗忘。忠实语言支持不自动否定数学独立性；内容会影响数学解题则按数学支持记录。
6. 精确判分验证识别后的数学内容；OCR/结构不确定返回 unknown，不记学生错误。教学题、调试题、保留验证题分开。

## 用户浏览器验收步骤

环境前提：迁移完成，登录同一工作区，启用上述教学开关；课程至少有一份可访问材料。测试助理原生工具另需启用查询开关并配置模型。浏览器步骤按仓库约定交用户执行。

1. 从课程学习进入 span。逐步看例题、补全步骤、提交独立新题；有理数/负数和第三坐标冲突应分别得到确定判分或 unknown，首答不被后续帮助覆盖。
2. 在同一题请求忠实语言支持及数学提示，检查独立性区别。看卡片答案、笔记/材料/历史解析后再提交，检查服务端实际交付记录；刷新/重试不重复记帮助。
3. 在 span 或本题助理中改变节奏、关键步骤或明确反馈。刷新后保持意图版本；“我是猜的/抄了答案”不改原始正确性，旧建议显示失效，结果未知的重试不越过旧请求。
4. 选择计划提案，先查看原/新时段与未排项，再接受；另外验证教学、卡片、笔记、记忆、判分争议各一次，重复接受不重复执行。
5. 创建延迟复测，在 Today 打开；到期前应明确拒绝发题/提交。达到自然间隔后完成未曝光题族，期间复习未知不得显示成已经证实的保持。
6. 在卡片、笔记、冲刺及助理查看共同状态；展开影子比较，缺样本显示无数据而非 0% 或已校准。旧版本/撤回/跨课程链接应明确拒绝或标未知。
