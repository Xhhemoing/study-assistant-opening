### 短验收清单（尚未在本轮执行）

前提：使用明确的候选环境及所属测试账号，付费模型先确认预算；浏览器由用户执行。每项最多 5 步。

1. **后台批改**：保存独立作答 → 离开页面 → 返回同一记录 → 查看唯一批改状态/结果 → 刷新确认不重复付费。
2. **修订与人工改评**：更正答案 → 核对新修订 → 查看旧结果不覆盖 → 人工改评 → 确认无自动重复收费。
3. **PDF/OCR**：上传合成 PDF → 确认物理页 → 制造受控失败 → 显式重试 → 确认只执行失败段且正文正确。
4. **答案隔离（B 候选）**：按题目/答案分类 → 未作答时检查学生和模型输入 → 显式看答案 → 核对曝光与独立资格 → 刷新/恢复后仍一致。
5. **冲刺导航/预算**：查看预算 → 从任务进入已有活动 → 核对目标 → 刷新 → 确认没有复制任务或更换活动。
6. **Explore（C 候选）**：默认 OFF 检查入口 → 直访 API/URL 被阻断 → 测试环境 ON 后预览 → 显式继续问 → 返回原任务/草稿；关闭后原提问仍可用。
