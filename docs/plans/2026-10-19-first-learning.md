# 首次学习实施计划

目标：从可跳过的首启表单进入真实教学活动，并得到每日规划设置和首个待安排任务。

范围：本工作区负责首启，不修改另一聊天正在整合的 Study 查询、教学决策或 migration。沿用现有鉴权、来源准入、活动/任务幂等键和计划草稿；不自动接受草稿、不记录掌握或完成，不改功能开关。

- [x] 新建 Web 内部 first-learning service/route：严格验证主题、目标、真实日期、学习时间和资料 ID；先用既有活动服务校验资料并创建幂等活动，再复用幂等手工任务、条件初始化和现有 daily draft。中途失败可用同一请求继续，不吞错。任务绑定原活动；跨日只允许事务内精确回执重放，禁止新建过期意图。

验收：用户在 /onboarding 输入主题/目标/日期/每日时间并可选资料；进入 /opening/today 后展示具体学习意图、实际生成状态与首个待安排任务。刷新/网络不确定后继续同一请求不重复创建；旧设置不被覆盖；开关关闭时明确说明并保留助理/笔记路径。用户完成一次讲解、作答与核对、结束与小结，再做延迟复测；记录卡住位置、待核对比例和费用。待用户浏览器及真实学习验收。

## 环境与用户试用

本切片无新 migration、依赖或环境变量，不自动修改功能开关。发布分支已有 0074；若先整合 Study 升级，按最终主干迁移末号部署。生成内容需要既有模型/worker 配置；完整教学工作台需既有教学试运行开关。关闭时只保存学习意图与任务，显示实际状态，不能据此认定已生成或学会。原有用餐/睡眠默认时段参与排程；冲突时可能出现待安排任务，用户可在设置中调整。已有计划不被自动接受或覆盖。

| 时机 | 操作 | 预期及要记录的内容 |
|---|---|---|
| 首次进入 | 登录后访问 /onboarding，填写具体主题、希望做到的事、可选目标日期、每日时段，并可选已解析材料 | 保存后进入今日页；出现具体意图和真实生成状态，任务保持待完成；已有时间设置保留 |
| 当天 | 从今日页的原活动或首次任务“开始此项”进入；阅读一个单元、独立作答、核对、结束并查看小结 | 两个入口进入同一活动，保留目标与材料；记录编译是否成功、待核对原因、卡住的步骤及可见费用 |
| 次日 | 刷新或重新登录，恢复活动；用保存/临时聊天查询实际学习记录，再点证据入口 | 断点及保存内容可恢复，临时问答刷新不恢复；查询时间和证据可追溯，不能把旧快照称为当前状态 |
| 首次作答至少 72h 后 | 按系统真实到期状态做延迟复测，尽量独立完成一题新变式 | 记录独立作答是否正确、是否需要提示；正常复习和见过答案不算独立迁移证据 |

浏览器、响应式、真实供应商和学习收益由用户验收；未得到反馈前均记为待验收。失败时保留原草稿/请求键，先查看今日页，避免把未知结果当作没有保存；修改内容代表新的学习意图。手工任务与实际作答事实分别记录，结束教学活动不会伪造任务完成。
