# Study × Explore 实施任务卡

配套 [完整开发方案](PLAN.md)。以本地 `/www/migrated/work/AIstudy` 当前 `codex/sprint-a0-20261023` 实际工作树为基线，包含未提交与 untracked 成果；不从部署版重新开工。新开发尚未执行。

## 第一批：可单独交付的最小体验

### 卡1：连续性验证与预览契约（P00/P01/P03）

**目的：**用户在原内容上开始局部解释，始终保留课程/资料/作答身份。

**前置：**读取当前本地工作树及相关新接口；与材料可信改动协调同一写入者；不要求它先部署或重写。

**实现范围：**

- 验证现有 Drawer 宽屏保持同一 AssistantSession；独立助理走现有 `/opening/assistant` 入口。
- 若增加展开链接，携带已保存会话与合法 binding；临时/创建中会话保持原宿主，不伪造可恢复 ID。
- 新增概念预览输入/响应判别联合及窄服务；支持来源固定版本、课堂块或已保存回答。
- 复用 materialPageReadable/资料修订与内容曝光；材料摘录和已存解释分开标识；没有证据就诚实返回状态。
- preview POST 不调用模型；收到内容才展示，交付先于客户端 ACK，重试复用逻辑 key。

**实际落点：**
`apps/web/src/features/opening/assistant/assistant-drawer.tsx`、`assistant-session.tsx`、`study-conversation-context.ts`；新增 `features/opening/concepts/*` 与相应 route/contracts；现有 database material/content-delivery 边界。

**不包含：**新 Agent 全页、分支数据库、全课图谱自动生成、AI 自动补释义、节点确认。

**完成标准：**同会话展开不重复调用；跨版本/他人/受限/闭卷内容被正确拒绝；预览无模型请求；曝光 ACK 丢失不恢复独立；原题草稿和返回位置保持。执行受影响单元/handler；改变交付SQL时补隔离PG集成。交用户浏览器验证，未反馈单列。

### 卡2：无模型示例课（P02，可并行）

**目的：**不用上传、配模型或预算就能理解“读→问一处→返回→尝试”的产品价值。

**实现范围：**独立 demo 页面，本地 reducer 状态；抽纯 Span 内容/图形/固定提示组件；固定反馈明确标示例；入口接 onboarding/readiness，退出不迁移成绩。

**排除：**不挂 SpanLessonSession、正式 auto-start、真实 course/attempt/observation/FSRS/BKT、模型请求和 job。若采用未登录页，只放行明确 demo 路由和静态依赖。

**完成标准：**业务写入与模型 transport 全部禁止时仍能完成；登录用户也不污染档案；键盘/窄屏/重置可用。真实课不受 demo 状态影响。

### 卡3：统一概念锚点（P04）

**目的：**资料、课堂、回答中的同一操作可预期。

**前置：**卡1；不需要卡2完成。

**实现范围：**ConceptChip/Preview；remarkConceptAnchors 接受确定候选映射；复用现有选区工具栏。浮层展示来源、正文及“继续问”；继续只预填当前绑定的输入。无图谱仍可选区提问。

**技术约束：**不破坏 citations/Markdown source ranges/KaTeX；多义词不乱绑；不标代码/公式/链接/编辑区；Math 段落扩大范围时显示实际带入内容。移动面板和桌面浮层共用状态，减少动效。

**完成标准：**预览不覆盖正文；Esc/焦点/滚动恢复；任意选区和自动锚点行为一致；重复打开不生成模型请求；已有复制/制卡/笔记不退化。

**第一批交付形态：**以上三卡合成一条能使用的体验；可以先只有可信材料摘录和显式追问，不需要分支表和无限画布。

## 第二批：持久讨论和自己的理解

### 卡4：上下文审阅与引用篮（P05）

**范围：**可删除的引用片段、不可移除的学习身份、请求后真实依据。每段来源/版本/定位可核对，顺序明确；复用现有输入上限，先单段再多段。不用“精确token百分比”表示未测量的数值。

**完成标准：**服务端拒绝伪造/越权引用；不静默扩大选区；删除片段不清空历史/曝光；无依据不伪造出处。若持久化多引用，备份和读取兼容同步完成。

### 卡5：可恢复浅层支线（P06，跨包负责人统一）

**范围：**现有 conversations + 一条分支关系；明确父会话、分叉轮次、类型、上下文策略、所选片段和返回点。创建与首条生成分开；创建不收费。

**依赖：**卡1/4。事务与幂等先于 UI；确认完成轮次是否不可变再决定是否需要修订引用，不先造消息快照库。

**实现要点：**

- deepen：片段+有限背景；rephrase：截止点历史；related：主题+选择片段。
- 保留 model/record_referents 的权限与语义差异、历史总预算和隐私来源链。
- 父后续消息/兄弟支线不混入，曝光跨支线保持，闭卷服务端拒绝。
- 关闭支线不自动完课；返回同一原活动；临时会话不静默持久化。
- 新关系进入现有备份/恢复/隐私/删除及空命名空间校验，不只改表定义。

**完成标准：**隔离PG验证同key并发、一致事务、越权、分叉前后历史、撤权、删除降级；备份恢复后关系与曝光等价；真实Worker恢复不重复调用。对话树UI仅在这些通过后接入。

### 卡6：自己的理解（P07a，先交付）

**范围：**明确用户原话→非评分AI反馈→用户修订→选择保存笔记，关联课程/来源/概念。利用 listen 入口，但不把闲聊隐式判成正式作答；不写掌握/FSRS/BKT。

**完成标准：**用户与AI文本归属分开，原话不可被覆盖，资料依据真实，费用未知不重发，保存可恢复。自由探索无课程时也能记录，不强制建课。

### 卡7：解释检查（P07b）

**范围：**版本化解释题、rubric与材料依据，复用本地 attempt/observation/grade-observation。current criteria.verdict 和 evaluatorVersion 保持兼容；新增解释rubric版本以契约方式处理。

**必须贯通：**任务身份→服务端 explain维度→批改→改评→资格→技能投影→撤回→备份。当前 retest 路径固定 transfer，不能直接套用。materialSourceRefs/materialAnswerRefs/manifestRevision必须沿用。

**完成标准：**正确短答、流畅错误、遗漏条件、来源争议均能处理；帮助后修订不算独立；解释不提升procedure/transfer维度；真实模型小样本与人工核对单列结果；没有实证不宣称学习收益。

## 第三批：长期整理

### 卡8：节点个人整理（P08）

**范围：**独立 accepted/dismissed/displayLabel 偏好；材料supported/needs_check不变。采用真实nodeId，接入现有稳定身份保留与referencedNodeIds并发检查，不按同名迁移。

**完成标准：**重新解析/重建后保留正确关联，改名不改技能事实，过期节点可见失效，不自动排课/写掌握。备份与并发更新冲突处理完整。

### 卡9：局部路径与可选收束（P09）

**范围：**当前父问题、当前点、直接旁支、返回点；移动列表，不做画布。可选一句收获；显式保存/回填引用，不自动合并全文。

**完成标准：**导航来自真实关系；原题不可用时诚实降级；关闭即返回，不要求每次写总结；区分话题树和知识先修关系。

## 所有卡共同完成条件（P10）

- 使用当前本地分支已有预算、权限、错误和恢复语义。
- 单元/handler/必要原生PG/Worker近测及受影响类型检查真实通过；正式CI保留全门禁。
- 不把自动测试、用户浏览器、真实模型质量与学习收益混成一个“已通过”。
- 指标用明确分母与unknown/not_collected，不采集不必要的答案全文。
- 每张卡交付实际改动、执行过的检查、遗留问题、用户验收步骤。当前任务卡只是方案，不是完成记录。
