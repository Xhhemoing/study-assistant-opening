# Opening 浏览器人工验收清单 · 2026-10-06

> 按仓库约定，浏览器验收由用户执行。本清单汇总当前所有“待浏览器人工验收”项，按流程顺序排列；每项含入口、步骤与预期。配套服务使用当前已启动的完整栈；历史分项保留原时点上下文，当前整改主链以以下 WP0.8 为准。
> 桌面 ≥1024px（Chrome/Edge 1440×900）；手机同步项另需一个移动浏览器或第二台设备。

## WP0.8 新账户五步冒烟（2026-10-25，待用户运行）

入口为 `tests/e2e/opening-smoke.spec.ts`，使用 `npm run test:browser:smoke`。Agent 只维护测试与非浏览器检查，本节未记录浏览器通过。

前提：使用允许真实新注册的验收环境，Web、Worker、数据库、队列及现有模型路由均可用；新账户应直接获得计划规定的默认模型能力，不先手工配置模型、预算、课程或材料。当前 Opening 隔离套件关闭注册，且其 PDF 测试供应商不支持本主链，不能拿旧套件通过代替。尚未接通的注册、默认模型或自动批改会在对应步骤失败，保留失败，不改成跳过或种入课程。

由用户在项目根目录运行，替换 URL 与完整已合并 SHA：

```pwsh
$ErrorActionPreference = 'Stop'
$env:E2E_BASE_URL = 'https://your-acceptance.example'
$env:AISTUDY_COMMIT = '<完整40位已合并SHA>'
npm run test:browser:smoke
```

专用配置不启动或重启服务，不重置库或认证计数，不导入 owner-seed fixture，也不替换业务接口。它会通过真实注册创建合成测试账户，并发送讲义、批改与助理请求。默认使用验收环境的实际模型；未来采用录制回放时必须注明回放来源，且第三步每周至少一次用真实模型执行。原两套 CI 浏览器用例保持原样，只有新增 spec 由专用入口运行。

### 本轮集成候选补充复验（待用户运行）

环境须运行本候选的 Web、Worker 和数据库迁移（含 0100），并使用本人或 QA 测试账户。测试期每日不限额需在该环境显式启用 `OPENING_MODEL_DAILY_QUOTA_MODE=unlimited`；本轮没有修改线上配置。

| 入口 | 操作与预期 |
| --- | --- |
| `/opening/agent` | 直接进入是新对话；没有待确认建议时不留右侧空栏。已有建议只显示当前对话，接受/拒绝统一进入建议收件箱；最后一项处理后右栏消失 |
| 原题的助理抽屉 → 在助理全页中打开 | 保留同一对话与原题背景；切换历史和新建对话不会串回旧题。背景读取失败时可重试，不能带错题发送 |
| `/opening/settings/ai#memory` | 可见已保存记忆和来源消息数量；不常显内部 ID，诊断选项在高级设置中默认折叠。取消删除不会改数据；旧设置首页 `#memory` 书签跳到本页 |
| `/opening/settings/ai` | 默认显示已保存的生效模型、测试期不限额和今日已用金额；待结算金额单列并包含此前未结算请求，读取失败显示暂不可用。展开“使用自己的模型”后才看到一键配置、路由和供应商；编辑尚未保存时摘要仍显示原模型 |
| 模型设置保存与一键配置 | 任一操作进行时，另一操作不能提交。配置结果未知时保留原请求确认入口；普通保存结果未知时停止更改并提示先确认服务端请求结束，不把重读当成保存成功 |
| 全新账户首次学习页 | 默认模型可用时不提示 AI 不可用；明确不可用时出现可关闭提示，关闭后同一草稿再次进入不重复提醒，学习草稿保留；网络或 Worker 状态未知不能当作确认不可用 |
| `/opening/courses` 列表与卡片视图 | 为进行中的课程设置“应试练习”及目标日期，课程“…”菜单可进入同一课程的考前冲刺；主课程链接仍独立可用。普通截止日期、未选应试模式、无日期及已归档课程不显示该入口；目标偏好暂不可读时课程列表仍可用。展开后菜单不能被卡片或滚动区域裁剪，键盘可以进入链接 |
| 学习开始页建议与课程目标设置 | 普通截止日期不显示为“考试”或冲刺建议，也不遮蔽稍晚的明确考试；过期与已归档考试不推荐。目标“随目标调整”的说明为最后 14 天，与既有策略一致 |
| 旧设置书签 `#export` / `#developer` / `#quick-model-setup` / `#daily-budget` | 跳至 AI 与数据页后定位对应目标并按需展开；异步用量加载后也能定位。无锚点时高级区仍默认折叠，手动关闭后不会被其他页面更新反复打开 |
| 带旧追问分支断点的学习活动 | 恢复已有测试活动，从目录或“下一单元”切换后，再打开/关闭工具仍停在新单元；回主线或保存失败时显示未确认状态，不能伪选中新单元。没有此类旧活动样本时标记待样本，不记通过 |
| 讲义选中文字 → 保存 | 笔记正文仅含所选片段，并保留原学习链接；不同选区可分别保存。保存中切换题目，晚回结果不能显示到新题或关联新课程；结果未知时保持原记录，不重复保存 |
| 已解析 PDF 的资料阅读页 | 打开 PDF，加载中切换到另一份 PDF，再返回原文件；随后关闭并重新打开阅读页。预览须能继续加载，旧文件的页码或文字不能出现在新文件中。若加载失败，错误和原件下载入口保留，点击重试应重新加载；没有出现失败时不把重试路径记为通过。本项待用户复验，不由远端 Worker 流程通过推导 |
| span / matrix 内置课程 | 顶部可返回、选目录、看单元进度及开关专注/工具；工具统一为对话/笔记/资料，资料显示本课程真实材料。目录选步不丢原答案；讲解帮助四词可用且键盘/触屏可达，“举个例子”只预填当前题目的问 AI 草稿，需自行发送 |
| `/opening/courses/<课程ID>?mode=sprint` 及其 `/study` 形式 | 跳到同课程的 `/opening/sprint?courseId=...`；重复查询参数与会话参数保留。旧 `/learn/courses/...` 书签也可到达，不丢登录、不循环跳转 |
