# Opening 浏览器人工验收清单 · 2026-10-06

> 按仓库约定，浏览器验收由用户执行。本清单汇总当前所有"待浏览器人工验收"项，按流程顺序排列；每项含入口、步骤与预期。配套服务：本地 `npm run dev`（PostgreSQL 5433 `aistudy_opening_dev`）或 hermes 部署（23.251.32.22，`6a58787`）。
> 桌面 ≥1024px（Chrome/Edge 1440×900）；手机同步项另需一个移动浏览器或第二台设备。

## A. 上传与材料（U02）

| # | 步骤 | 预期 |
|---|---|---|
| A1 | 助理页 → 回形针 → 选择 PDF 上传 | 进度条真实推进；"解析中 → 已完成"状态更新 |
| A2 | 上传一个 >上限或不支持的文件 | 明确错误提示 + 可重试，不显示成功 |
| A3 | 上传中断网 | 错误提示；恢复后重试成功 |
| A4 | 刷新页面 | 材料列表保持，状态不丢 |
| A5 | 点开已解析 PDF | 分页预览；"下载原件"得到与原文件一致的文件 |

## F. LAB-U01 动作 chips（本次新增，重点验收）

前置：完成 D1–D2（存在练习会话与曝光）。

| # | 场景 | 点哪个 chip | 预期 |
|---|---|---|---|
| F1 | 无提示曝光、已选材料页 | 继续引导讲解 | 输入框预填"只给提示"文案 **且模式切到"给我一点提示"**；不自动发送 |
| F2 | 有 hinted 曝光 | 看完整例题 | 模式切到"帮我讲清楚"+预填讲解请求 |
| F3 | 有 revealed 曝光 | 试一道独立变式 | 预填含技能名/原题引用的独立作答请求，明示"不要先给提示"；发送走既有 T03 |
| F4 | 有到期重测（未接受） | 到期重测 | 提示"已接受 N 个"；到今日任务队列可见新任务；**重复点击不重复建任务** |
| F5 | 重测已接受过 | 到期重测 | 提示"没有待接受的重测任务"，指向今日队列（打开而非重复 accept） |
| F6 | 未选材料页 | 先选定材料页 | 打开材料/页码选择器 |
| F7 | 全程 | — | 不出现任何掌握百分比/进度条；推荐在 pending/加载中时禁用 |

## 已知边界（不算失败）

- 本地无 Redis/MinIO 时上传桌面版 handler 集成被环境阻塞（CI 覆盖）；
- 真实模型回答质量不在本清单范围（fixture/预算已在 CI 与集成层验证）；
- 遗留 workspace 页面（/learn /explore /library 三入口导航）已被 Opening shell 替换，属待 Heidi 决策的退役/改写集合，不在验收范围。
