> **状态：** v1.0（2026-11-28），取代 2026-07-21 的 Baseline v0.2。理念与原则以 [LEARNING_THEORY.md](LEARNING_THEORY.md) 为准；界面与 AI 交互细则见 [UX_AND_AI_POLICY.md](UX_AND_AI_POLICY.md)；场景预设见 [SCENARIOS.md](SCENARIOS.md)；考前冲刺模块见 [exam-sprint.md](exam-sprint.md)；开发安排见 [roadmap/](../roadmap/OVERVIEW.md)。

## 1. 产品定义

AIstudy 是云端优先、面向终身使用的 AI 学习空间。**目标学习、自由探索、笔记与知识库**是三个平等入口，共享同一套资料、笔记、卡片、关系与学习事件。课程是可选的长期上下文，可以叠加多个目标与时间窗口；用户也可以在没有课程、目标和计划的情况下自由阅读、追问、记录、连接和创作。

### 核心价值

1. 不必先搭知识体系，上传资料、选一个卡带或直接提问即可开始；
2. 区分“受助做对”和“独立做对”，并用延迟后的新题证明学会；
3. 上传带答案的资料时答案自动封存，不剧透；
4. 三个入口之间无损流转：探索可沉淀为笔记、卡片、课程，课程疑问可转入探索；
5. 能力分识别、回忆、程序执行、迁移、表达、限时、长期保持，不用单一掌握度误导；
6. 默认界面结果优先、只给一个下一步，专家与开发者仍可查看依据；
7. 全部资产可导出带走；
8. 国内与海外、中英双语、桌面与手机都可用。

## 2. 目标用户

全部人群同等对待、全部试用：

| 人群 | 主要入口 |
|---|---|
| 大学课程学习者 | 目标学习 + 笔记 |
| 考试备考者（考研、考公、职业资格等） | 目标学习 |
| 语言学习者（IELTS/TOEFL 等） | 目标学习 + 探索 |
| 海外学生（英文课程） | 三入口 |
| 职场技能提升者 | 目标学习 + 探索 |
| 兴趣与自学者 | 自由探索 + 笔记 |
| 研究与写作者 | 笔记 + 探索 |
| 终身学习者（关闭计划） | 三入口自由组合 |
| 中学生（监护人同意与未成年人保护就绪后） | 目标学习 + 探索 |

次要用户：教师与资源作者、学习小组组织者、自定义策略的高级用户、自托管与插件开发者（商业化阶段再评估）。

## 3. 三个平等入口与功能范围

### 3.1 目标学习（`/opening/today` 为入口）

- 今日：继续上次、快任务、临时减量与跨日改排；
- 课程：多目标与时间窗口、考纲路线、课内 AI 主讲、讲义阅读、交互课（span/matrix 等）、同名知识点确认；
- 练习与批改：文字/拍照作答、帮助阶梯、确定性判分、AI 批改反馈、显式二次批改、自核；
- 复习：间隔复习、延迟复测、薄弱点、按时长复习、离线闪卡；
- 冲刺：模拟卷、考试分数预测、临考策略覆盖；
- 卡带工坊：考试与技能卡带（IELTS 写作口语、408 等），无需先建完整课程即可试用。

### 3.2 自由探索（`/opening/agent` 为入口）

- 会话与分支、开放对话与图解、待确认沉淀与记忆；
- 无需建课即可上传文件、拍照、录音直接提问；
- 一键沉淀为笔记、卡片或升级为课程；
- 粘贴外部 AI 讲解并安排复述；
- 错因记忆的查看与纠正；
- 随行“问 AI”抽屉在所有页面可用。

### 3.3 笔记与知识库（`/opening/library` 为入口）

- 笔记：块编辑、双链与反向链接、属性、关系、版本历史、草稿冲突合并、AI 修订建议（答案块脱敏）；
- 资料：全格式上传、PDF/音视频阅读、答案封存、划词追问与存笔记；
- 写作：多稿、四维批注、单句润色；
- 知识地图：个人知识资产图、自由画布、考纲路线、跨课共享技能；
- 搜索（⌘K）与导出（Markdown / Anki / 完整归档）。

### 3.4 全局与公开层

- 设置：学习偏好与关闭计划、AI 模型与额度、连接器（邮箱、钉钉等）、导出、评测集；
- 公开：`/try` 90 秒体验、`/s/[token]` 分享卡；
- 注册：区域、语言、年龄段、默认入口三选一。

> 每项能力必须有真人可达入口；当前尚未接入入口的能力见 [roadmap/ARCHITECTURE_PLAN.md](../roadmap/ARCHITECTURE_PLAN.md#4-接线清单)。

## 4. 核心用户流程

### 4.1 首次启动
1. 注册（选择区域、语言、年龄段；未达门槛进入监护人同意流程）；
2. 三选一开始：上传资料 / 选考试或技能卡带 / 直接开始探索；
3. 目标路径可选期末、高考、考研或自定义场景；自由路径可从问题、文件、网页、笔记或空白开始。

**成功标准：** 新用户 15 分钟内开始首个有效活动（候选目标：首个有效动作 P50 ≤ 3 分钟）。

### 4.2 日常学习
1. 首页（用户的默认入口）显示继续上次与一个主操作；
2. 练习、回忆、解题、阅读、探索或写作；
3. 系统记录答案、帮助、用时；把握度与错因只在高价值时询问；
4. 结束时显示结果摘要与下一步；需要时展开原因或纠正判断。

### 4.3 验证与复测
用户选择“验证我会不会”时进入无提示作答；之后系统安排延迟复测（用未见过的同类题）。

### 4.4 周期复盘
比较计划与完成；显示新增风险、持续问题与已稳定内容；高影响调整须用户确认。

### 4.5 考后处理
长期保留 / 降频 / 季节归档 / 停止复习但保留记录 / 导出后删除。

## 5. 非目标

- 通用文档协作平台与多人实时编辑；
- 自动构建完整知识本体；
- 强迫所有知识卡片化或教材化；
- 公开排名、强制打卡、大型社交信息流；
- AI 自动决定学习事实；
- 对任意外部软件承诺无损迁移；
- 把今日计划作为唯一主页或使用前置条件；
- 为探索、课程、知识库分别建立互不相通的数据模型；
- Beta 期内收费或接入支付。

## 6. 成功指标

| 类别 | 指标 |
|---|---|
| 激活 | 首日激活（完成首个有效活动）；首个有效动作用时 |
| 留存 | 第 4 周留存；每周学习天数；回访率 |
| 目标学习 | 北极星：一周后无 AI 同类未见题独立正确率（÷ 有效用时），口径见 [DECISIONS.md](../decisions/DECISIONS.md#测量口径原文保留)；受助 → 独立转化 |
| 自由探索 | 探索沉淀率；自愿验证比例 |
| 笔记与知识库 | 持续创作天数；双链与复用；导出次数 |
| 质量 | 导出再导入恢复率；后台任务失败可重试且不重复写入；批改误判率及上界 |
| 成本 | 每账号每日/每月模型成本（P50/P95，按区域） |
| 商业 | 付费意向率（R3 调研） |

阶段退出阈值为建议值，在体验与数据后调整（见 [roadmap/OVERVIEW.md](../roadmap/OVERVIEW.md)）。

## 7. 已确认产品决定

- 云端 Web 优先，同一代码在国内与海外各一套部署；最小 PWA 支持手机安装、拍照、录音；
- 默认界面结果优先，开发者设置可查看中间步骤；
- 场景预设可继承与覆盖，不写死单一复习方法；
- Beta 期国内与海外均免费，提供每账号每日免费额度；
- 数据模型与权限不得假设所有用户都是成年人；
- 其余决定见 [DECISIONS.md](../decisions/DECISIONS.md)。
