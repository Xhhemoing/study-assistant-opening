# 场景预设与学习策略

## 1. 设计目标

场景预设不是固定课程，而是一份可版本化、可继承、可覆盖的策略配置。它决定系统优先收集哪些信息、安排哪些任务、如何显示结果和何时切换阶段。

用户选择一个预设后，可以只修改少量常用项；高级用户可在开发者设置中查看完整继承结果并覆盖参数。

## 2. 统一策略协议

每个 `StrategyPreset` 包含：

```text
identity              模板ID、版本、适用考试
calendar              考试日期、阶段和里程碑
scope                  科目、考纲和资料范围
abilityRequirements    各类能力的目标要求
activityMix            回忆、基础题、程序题、迁移题、输出、模考比例
scheduling             间隔、每日上限、逾期处理和跨科分配
evidenceRules          哪些行为可改变状态，证据最低要求
statusThresholds       稳固、可用、薄弱、未测的映射规则
interventionRules      不同原因对应的解决路径
archivePolicy          考后保留、降级、归档和删除策略
uiSummary              默认展示哪三个结果指标
```

覆盖顺序：

```text
系统基础模板
→ 考试场景模板
→ 科目模板
→ 资源包建议
→ 用户偏好
→ 临时冲刺覆盖
```

上层不能静默覆盖用户明确修改。每次模板更新必须展示差异，并允许继续固定旧版本。

## 3. 能力要求矩阵

系统不假设所有知识都需要相同学习方式。

| 能力类型 | 典型任务 | 可用证据 |
|---|---|---|
| 识别 | 选择、判断、概念辨认 | 正误、干扰项、信心、时间 |
| 无提示回忆 | 填空、定义、公式、口述 | 是否提示、答案完整度、延迟表现 |
| 程序执行 | 数学解题、代码、实验步骤 | 步骤、顺序、检查点、错误位置 |
| 迁移应用 | 变式、综合题、新情境 | 与练习题距离、策略选择、独立完成度 |
| 表达输出 | 论述、作文、证明、口试 | 量规维度、结构、证据、修订记录 |
| 限时稳定 | 整卷、限时章节、模拟考 | 完成率、时间分配、失误和波动 |

不同考点可要求不同组合。例如历史年份重视回忆，数学大题重视程序执行和迁移，作文重视表达与限时稳定。

## 4. 期末考试预设

### 目标

在较短周期内覆盖教师指定范围，快速发现章节缺口并达到课程考核要求。

### 默认阶段

1. **范围确认：**导入课程大纲、教师讲义、作业和往年题。
2. **短诊断：**每章少量代表题，不追求完整测试。
3. **补缺：**优先未测和高权重薄弱章节。
4. **整合：**跨章综合题、论述或项目输出。
5. **模拟：**按教师题型和时长完成整卷。

### 默认策略

- 课程范围和教师材料权重高于通用知识体系；
- 临近考试时允许战略放弃低权重内容；
- 不要求为所有知识创建长期卡片；
- 考后默认归档应试细节，保留先修核心和错因总结。

### 默认首页

- 范围覆盖；
- 高风险章节数；
- 今日预计时间；
- 主操作：继续今日复习。

## 5. 高考预设

### 目标

在长周期、多科目和多轮复习中平衡基础覆盖、专题突破、迁移能力和整卷稳定。

### 默认阶段

1. **一轮：**考纲覆盖与基础程序；
2. **二轮：**专题、变式和跨章节迁移；
3. **三轮：**整卷、时间分配、稳定性和错因压缩；
4. **考前：**高价值回顾、睡眠和任务降载。

### 默认策略

- 跨科时间根据目标差距、边际收益和考试权重分配；
- 基础题稳定后降低重复量，转向迁移与限时；
- 模考证据比非限时练习更能影响“考场可用”状态；
- 记录粗心、审题、时间、策略和知识错误的区别；
- 禁止单次模考导致剧烈改计划，使用多次趋势和人工确认。

### 默认首页

- 今日科目安排；
- 高风险专题；
- 最近模考趋势；
- 主操作：开始第一项任务。

## 6. 考研预设

### 目标

围绕明确考试日期协调公共课、专业课、真题版本、背诵、解题和输出训练。

### 默认阶段

1. **基础：**教材、课程和核心概念；
2. **强化：**专题题型和系统练习；
3. **真题：**按年份、命题风格和评分规则训练；
4. **冲刺：**背诵输出、整卷和高频风险；
5. **考前：**保留核心，不再无边界扩充资料。

### 默认策略

- 真题和目标院校信息必须带年份与版本；
- 公共课与专业课使用不同能力组合；
- 背诵材料必须有无提示输出验证，不能只记录阅读次数；
- 专业课论述要求结构、证据和限时输出；
- 资源更新不得静默改变用户已固定的目标年份。

### 默认首页

- 距考试天数；
- 各科计划偏差；
- 真题与输出完成情况；
- 主操作：执行今日优先任务。

## 7. 自定义场景

用户只需设置：

- 目标名称和日期；
- 内容范围；
- 可用时间；
- 目标能力；
- 是否需要长期保持；
- 是否需要限时和正式输出。

系统根据这些信息生成模板副本。开发者模式允许调整全部字段并导出模板。

## 8. 常用用户调整

默认设置页只开放：

- 每日学习时间；
- 休息日；
- 科目优先级；
- 复习强度：轻量、平衡、冲刺；
- AI介入：手工、副驾驶、教练；
- 是否先答后提示；
- 考后处理；
- 是否允许系统自动调整今日任务。

完整参数只在开发者设置开放，并提供恢复模板默认值和变更预览。

## 9. 场景切换

从期末切换到长期学习，或从基础阶段进入冲刺阶段时：

- 保留已有事件和个人状态；
- 新模板只改变未来计划，不重写历史；
- 显示任务组合和阈值变化；
- 高影响变化需确认；
- 允许回滚到上一策略版本。
