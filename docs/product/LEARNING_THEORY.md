## 1. 一句话与核心命题

**一句话：** AIstudy 是一个面向所有人的 AI 终身学习空间——想学什么都行，想怎么学都行，并且能证明你真的学会了。

**核心命题：**

1. **学习没有唯一形态。** 备考、上课、自学、兴趣、职业、研究、创作都是学习。产品不强迫任何人先定目标、先建课、先诊断。
2. **三种学习方式平等，彼此流转。** 目标学习负责方向与节奏，自由探索负责问题与发现，笔记与知识库负责长期积累与创作。
3. **讲解是商品，证据与连续性才是产品。** AI 讲解已人人可得；我们提供的是：知道你**独立**能做什么、跨周记得你的问题与作品、扎根于你自己的资料。
4. **帮助随时可用，验证时才撤掉。** 学习时可以随时求助；当你想确认“我是不是真会了”，系统给无提示的作答，并在之后用没见过的同类题复测。
5. **你的知识资产属于你。** 可导出、可迁移、可追溯；付费永远不是数据赎回费。
6. **AI 是安静的伙伴。** 它解释、提出候选、在后台准备；事实、资格、权限与写入由确定性程序裁决；不替你思考，不擅自改你的安排。

## 2. 我们对“AI 时代的学习”的判断

| # | 判断 | 依据 | 对产品的含义 |
|---|---|---|---|
| J1 | 讲解、分步引导、“上传资料生成闪卡/测验/导图”已被大厂免费化 | ChatGPT 学习模式（2025-07）、Gemini 引导式学习、NotebookLM、Claude 学习模式；国内豆包、夸克、作业帮、小猿等 | 不以“AI 会讲解”作为卖点 |
| J2 | 无约束的 AI 帮助会提高练习成绩、却损害撤掉 AI 后的表现；有设计的导师能缓解 | Bastani 等，PNAS 2025（普通 GPT 组练习 +48%，撤工具后 −17%）；Kestin 等，哈佛物理随机试验（即时后测更好、用时更少） | 必须区分“受助表现”和“独立表现” |
| J3 | 即时收益不等于持久收益；间隔提取练习稳定有效 | 2026 年逾 6,000 名中学生随机试验一周后收益偏弱；七周大学生研究支持间隔提取优于自主 AI 学习 | 用**延迟后、没见过的题、独立作答**衡量学会 |
| J4 | 学习者越依赖 AI，越需要可信的个人记录 | 推断 | 跨周连续性、可追溯证据、可导出资产是信任基础 |
| J5 | 不存在固定的“学习风格”决定效果 | WWC 等综述 | 偏好决定表达与节奏，目的决定训练要求 |
| J6 | 一个人一生会在多种学习形态之间切换 | 推断 | 一个空间承载三种方式与所有人群，而不是为每类人做一个产品 |

**AIstudy 的四个独有体验**（对外重点讲）：
1. 上传带答案的教材或真题，答案自动封存、不剧透；
2. 区分“看提示做对”和“自己做对”，之后用新题复测；
3. 探索对话一键变成笔记、写作或课程练习，反之亦然；
4. 全部资产一键导出带走（Markdown / Anki / 完整归档）。

> “跨周证据值得用户回来查看”仍是产品假设，用回访率与自愿复测率验证（见第 16 节）。

## 3. 学习者与学习形态

**面向所有人群，全部建设、全部试用：** 大学课程学习者、考试备考者（考研、考公、职业资格等）、语言学习者（IELTS/TOEFL 等）、海外学生、职场技能提升者、兴趣与自学者、研究与写作者、终身学习者，以及在监护人同意与未成年人保护就绪后的中学生。国内与海外均支持。

**能力不是单一的“掌握度”。** 区分七类能力：识别、无提示回忆、程序执行、迁移应用、表达输出、限时稳定、长期保持。

**卡片不是所有知识的终点。** 事实性知识适合回忆与间隔复习；程序性技能靠步骤、例题、项目与调试；表达与隐性能力靠作品、案例、模仿与反馈。

**偏好 ≠ 目的。** “喜欢短讲解”决定表达方式，不代表只需要浅层理解；训练要求由真实目的决定。

## 4. 三个平等入口与流转

### 4.1 三个入口

| 入口 | 回答的问题 | 典型内容 |
|---|---|---|
| **目标学习** | 我要达成什么、下一步做什么 | 今日、课程、目标与时间窗口、练习、复习、冲刺、考试与技能卡带 |
| **自由探索** | 我想追问什么、发现什么、尝试什么 | AI 对话与分支、资料追问、假设、开放问题、探索项目 |
| **笔记与知识库** | 我积累了什么、要创作什么 | 块笔记、双链、属性、版本、资料阅读、写作、知识地图、搜索与导出 |

三个入口共享同一套资料、笔记、卡片、关系与学习事件，不建互不相通的数据系统。**采集收件箱**贯穿三个入口，不是第四个顶层入口。

### 4.2 自由度保护契约（9 条，必须始终成立）

1. 三个顶层入口同级；
2. 用户可设默认入口，并可关闭今日计划；
3. 探索无需课程、目标、诊断或完成待办；
4. 计划外学习不标记为失败；
5. 课程结构、评价、间隔复习、AI 可分别关闭；
6. 每门课可选手工、副驾驶或教练模式；
7. 可预留不被考试计划占用的自由探索时间；
8. 自动整理、建卡、调计划各有独立开关；
9. 系统解释影响，但不以惩罚或功能锁定强迫执行。

### 4.3 流转规则

- 探索可以转为课程材料、笔记、卡片、题目、任务或新课程；目标学习中的错题、疑问可以转入探索。
- 回到目标时，由用户决定探索结果中哪些影响原任务。
- 探索内容的沉淀生命周期：`scratch → candidate → confirmed → published → archived / discarded`。默认是草稿；完整聊天不默认进入知识库；AI 提候选，用户逐项接受；提升时保留出处。
- 无课程活动**零隐式欠账**：不自动排程；只有用户明确说“帮我留 15 分钟”才产生一次性候选。

## 5. 目标学习

- **课程是长期容器**，可叠加多个目标与时间窗口；课程只引用资产，不复制资产；移出课程不删除资产。
- **时间窗口 7 类：** 固定期限、周期安排、弹性习惯、项目里程碑、临时冲刺、休眠维护、无计划自由探索。
- **当前学习要求 = 课程基础要求 + 活跃目标要求 + 时间窗口修正 + 用户覆盖。** 目标切换只改变未来策略，不改写历史。
- **计划只是建议层：** 可关闭、重排、跳过；高影响调整须确认且可回滚；禁止因单次模考剧烈改计划。
- **长短期目标并存：** 时间不足时服务当前目标，并如实保留“未验证”的内容。
- **前置补习：** AI 可沿有依据的知识图谱补必要前置知识，必须有范围、有预算、有原任务；没有证据不补，补习不传播掌握状态。前置条件以解法为单位：同一解法内全部满足（AND），替代解法之间满足其一（OR）；章节顺序不等于能力依赖。
- **策略模板覆盖链：** 系统 → 考试场景 → 科目 → 资源包 → 用户偏好 → 临时冲刺。上层模板不得静默覆盖用户的明确修改；模板更新展示差异并允许固定旧版本。
- **临考策略：** 临近考试时提高模考、错题和限时任务权重是**可调的产品规则**（默认 7 天），不是研究结论。
- **考后处理五选一：** 长期保留、降频、季节归档、停止复习但保留记录、导出后删除。
- **考试与技能卡带**（考研、IELTS、408 等）是挂在目标学习下的内容包与引导预设，共用同一引擎与证据账本，不为任何人群另造页面或引擎。

## 6. 自由探索

- 可从问题、文件、网页、笔记、错题、拍照、录音或空白开始；不需要课程、目标、诊断或计划。
- 支持从任意回答分叉新的探索线；右侧沉淀区可一键生成笔记、卡片或升级为课程。
- 探索中的 AI 帮助不受限制；探索**不强制测验**。用户可以随时选择“验证我会不会”，这时才进入无提示作答。
- 外部 AI 的讲解可以粘贴进来，并安排“用自己的话复述”。

---

## 7. 笔记与知识库

- 笔记是长期创作的核心，不只是收纳层。唯一根模型：Document / Block / Relation / Property / Revision，块 ID 稳定。
- 编辑、阅读、学习是同一份内容的三种投影；学习视图引用原文块，不复制正文。
- 不强迫教材化或卡片化；智能排布只出可撤销的提案，永不静默重排正式内容。
- 卡片与练习回链到具体块与版本；来源变化时提示复核。
- 上传带答案的资料时，答案块自动封存，不进入检索、讲解与导出，直到用户主动查看。
- 写作（含多稿、批注、润色）属于知识库；写作类活动不产生能力观察（`MASTERY_NOT_ESTABLISHED`）。

## 8. 帮助与证据（本理论的核心）

### 8.1 帮助

- **帮助永远可取。** 用户随时可以要提示、看讲解、看答案。
- **帮助阶梯：** 独立尝试 → 方向提示 → 步骤提示 → 局部示例 → 完整答案 → 新情境重做。
- **防代学六步**（程序性、迁移、表达任务的默认流程，可跳过）：先尝试 → 最小提示 → 保留原答 → 展示差异 → 重做 → 新情境迁移。
- **已交付的帮助才算帮助：** 后台准备好（Prepared）不等于交付（Delivered）；预取与浏览不计为受助。
- **讲解按需即时生成**，不预生成；涉及复测时先告知“现在看会影响独立验证”。
- 新学内容示例渐退；巩固阶段先答后提示。两轮完整纠偏仍不行就换方式，用户可提前要求换。

### 8.2 证据分级（互不替代）

| 级别 | 含义 | 对用户的状态词 |
|---|---|---|
| E0 | 看过、读过、收藏、AI 代答、看懂解析 | 不是能力证据 |
| E1 | 用提示做对（受助） | 薄弱 / 未测 |
| E2 | 首次独立做对 | 可用 |
| E3 | 延迟后、没见过的同类题独立做对 | 稳固 |

- **首答一经提交即固定**；事后改答案，该次首答永久失去独立资格。
- **独立证据只在用户选择验证时产生**：验证作答不提供提示；用户在验证中主动求助，该次降为受助。
- **自核（对照参考答案后自报对错）**：可以推进普通练习（显示“已自核，可继续”），但不计入“已掌握”、复测通过、整课验收与北极星。
- **按已批准的 D7，“已掌握”和“已验证”暂只认确定性判分**（如程序可验算的答案键、精确有理数校验等；内置 Math I 示例题包当前仅程序判分的选择题计为已验证）；AI 批改照常给反馈，但不计入（计算题与证明题当前只给反馈，不计已验证）；后续经校准判分是否准入须经所有者另行批准。
- 用户可直接改评，不走审核流程；原记录保留，并更新有效评价。
- 阅读、打开、翻译、摘要、收藏、AI 代答、“AI 记得你看过”都不提升掌握。
- 作品分数高但无法独立重做，不能宣称能力提升。

### 8.3 三件事分开展示

**学习覆盖**（学过什么）、**能力证据**（独立能做什么）、**目标准备**（离目标还差什么）分开展示，不合成一个百分比。潜在掌握、下一题答对概率、考试分数预测分开表达；任何估计器（BKT、FSRS 等）都只是可替换的内部工具。

## 9. AI 的角色与边界

- **分工：** AI 负责解释、提出候选、理解意图；证据资格、时间、权限与写入由确定性程序裁决。
- **AI 修改只生成提案（diff）**，不直接覆盖正式内容；来源事实、正式答案、历史事件禁止静默修改。
- **8 种 AI 角色**（只改变交互策略，不建新数据系统；课程可设默认角色，用户可逐次覆盖）：检索者、解释者、导师、对手、编辑、考官、合作者、静默助手。
- **三档介入模式**（统一命名）：手工（AI 只响应请求）/ 副驾驶（默认，生成候选，写入前确认）/ 教练（在用户设定的预算内调整今日队列，每日摘要可一键撤销）。冲刺不是第四种模式，而是临时策略覆盖。
- **自动执行的条件：** 只有同时满足“可撤销 + 有变更摘要 + 用户事先授权”的操作才自动执行，否则只出草案。
- **外部与导入内容一律视为不可信数据**，其中的指令不当作系统指令。
- **个人浏览与发送给 AI 分别授权**；资料被排除出 AI 使用后，本人仍可阅读。
- **AI 失败不阻塞学习：** 模型不可用时降级为规则队列，手工闭环始终可用。
- **AI 生成内容明确标识**（界面显式标识与文件隐式标识）。
- **询问要有价值：** 答前三档把握度、错因选择等只在信息价值高时询问，且可跳过。

## 10. 长效学习伙伴（后台 Agent）

- **薄协调器 + 强领域模块：** 事实保存在各业务模块，协调器只查询与组织，不新建持久状态。
- **注意力三档：** 静默就绪（不打扰）/ 归来摘要（回来时合并展示变化）/ 阻塞需决策（只在用户选定的条件下打断）。
- **授权不可推定：** 已有目标、草案或后台作业都不等于授权；改变已接受的安排须符合授权；跨课挤占时间须显示代价。
- **显式恢复直达：** “继续 B 稿”不经模型直接恢复；“现在的安排”与“接着上次”是两个入口；后台生成不抢占“上次”。
- **后台整理只产出可证伪的假设**，禁止改写学情、写帮助记录或抢占“接着上次”。
- **活动接入四级能力：** L1 可接续（必选）、L2 可排程、L3 资料变化响应、L4 教学证据（后三项按需）。

## 11. 记忆与知识资产主权

- **记忆中心：** 可查看、纠正、限定作用域、暂停、导出、忘记；彻底删除覆盖数据库、对象存储、向量、缓存，并出删除报告。
- **导出：** 原生格式无损；Markdown / HTML / Anki 等投影须给出损失报告。
- **资产地图是只读投影：** 不建课、不写入、不触发模型；关系标注 recorded / derived / suggested 来源，推测关系不参与验证。
- **权限不泄漏：** 范围不随遍历扩大；无权限对象不能从边、计数或警告中被反推；统一返回“不存在”。
- **共享内容、个人状态、班级状态三者分离**；内容更新不覆盖个人历史。

## 12. 体验原则

- **三层信息：** 结果层（状态词 + 少量数据 + 下一步）→ 原因层（为什么、怎么改善）→ 开发者层（规则、版本、原始事件）。
- **状态词：** 稳固 / 可用 / 薄弱 / 未测；不用“95% 掌握”式文案；原因必须指向可执行的干预。
- **首屏只有一个主操作；继续上次优先**；没有证据时不填假进度、不显示掌握百分比。
- **无负罪感、无虚假紧迫**；中断、跳过不生成懒惰或自律标签；不做公开排名、强制打卡、泛信息流。
- **上手：** 新用户 15 分钟内开始首个有效活动（候选目标：首个有效动作 P50 ≤ 3 分钟）；注册时三选一默认入口（上传资料 / 选考试或技能卡带 / 直接开始探索）。
- **生成期间不让用户干等：** 后台生成时可先做练习，只在阻塞时提示。
- **随时随地：** 桌面深度学习；手机拍照、录音、扫码传草稿、碎片复习；中英双语；状态不只靠颜色表达，所有图表有文字摘要，可键盘操作。

## 13. 怎样才算“真的学会了”

- **北极星（目标学习）：** 一周后、不用 AI、同类未见题的独立正确率（÷ 有效用时）。逐项报告应测、独立对、独立错、受助、缺测、拒判/无法判定的分母；结果未知记为 unknown，不填 0；不能只保留完成者。精确口径见 [DECISIONS.md](../decisions/DECISIONS.md#测量口径原文保留)。
- **自由探索：** 回访率、探索沉淀为笔记/课程的比例、自愿“验证我会不会”的比例。
- **笔记与知识库：** 持续创作天数、双链与复用、导出次数。
- **不能单独证明学习收益的指标：** 任务完成率、聊天次数、使用时长、估计器拟合度。
- 产品内复测与研究测验分开；小样本只报告可行性与效应量估计，不宣称因果效果。

## 14. 开放、商业与信任

- **Beta 期国内与海外均免费**；商业化在体验与数据验证之后决定。
- **开放数据、协议与迁移**，不以阻止导出作为护城河；付费不能成为数据赎回费。
- **Open-Core：** 社区版 Apache-2.0，私有内核 UNLICENSED；不支持的能力如实返回 unsupported（见 [ADR-v3](../decisions/ADR-v3-open-core-and-engine-boundaries.md)）。
- **自带密钥（BYOK）不得静默回退到平台密钥**；按可用结果计次。
- **未审核的 AI 内容不得与审核内容共用质量标识。**
- **合规与未成年人：** 国内公开测试按面向公众的生成式 AI 服务准备；海外遵守当地隐私与儿童保护法规；注册收集年龄段，未达当地门槛的用户须监护人同意；数据模型不得假设所有用户都是成年人。

## 15. 已统一的历史矛盾

| 矛盾 | 统一结论 |
|---|---|
| 允许看答案 vs 不提供直接给答案 | 帮助永远可取；独立证据只在用户选择验证时隔离 |
| 主导航：三入口 / 今天·助理·课程 / 学习·复习·资料 | 以三入口为唯一真源；今日属于目标学习 |
| 低风险调整默认自动 vs 不静默改计划 | 可撤销 + 有摘要 + 事先授权才自动，否则只出草案 |
| 每题必问信心与错因 vs 只在高价值时问 | 只在信息价值高时询问，可跳过 |
| 开源许可多套方案 | 以 ADR-v3 为准 |
| 自由/建议/教练 vs 手工/副驾驶/教练 | 统一为手工 / 副驾驶 / 教练 |
| 预生成讲解 vs 按需生成 | 按需生成 |
| 稳固·可用·薄弱·未测 vs 内部证据等级 | 用户状态词按第 8.2 节映射 |
| 临考 7 天转应试 vs 偏好不等于目的 | 可调产品规则，不是研究结论 |
| 首发只服务单一人群/单一考试/市场先行 | 全人群、三入口、免费 beta；市场等平台能力在商业化阶段再评估 |

## 16. 仍是假设、需用体验与数据验证的

1. 跨周的独立证据会让用户愿意回来；
2. 自由探索与笔记的用户也会自愿做“验证我会不会”；
3. “状态词 + 少量数据 + 一个行动”比仪表盘更能推动学习；
4. 统一引擎 + 卡带足以覆盖各类人群的差异；
5. 免费额度下的模型成本可被未来定价覆盖；
6. 后台伙伴的“归来摘要”比主动提醒更受欢迎。

这些假设不靠预先判断取舍，而是在每个阶段结束时用你的亲身体验与试用数据回答。

## 17. 术语表

| 术语 | 含义 |
|---|---|
| 受助 / 独立 | 作答过程中是否实际收到过帮助 |
| 首答 | 某题第一次提交的答案，提交后固定 |
| 自核 | 对照参考答案后自报对错 |
| 确定性判分 | 程序可验算的判分（答案键、符号等价、有理数校验等） |
| 延迟复测 | 间隔一段时间后用未见过的同类题独立作答 |
| 卡带 | 挂在目标学习下的考试/技能内容包与引导预设 |
| 沉淀 | 把探索或对话中的内容提升为笔记、卡片、课程 |
| 归来摘要 | 用户回来时合并展示后台准备与变化 |
