## 结论（一句话）

关联能力**已有**（材料库批量「归入课程」→ `POST /api/courses/:id/memberships`），但**入口深、步骤多、课程页不能加只能移**；R2 后又从侧栏/命令面板拿掉材料库，发现性很差。

## ① 入口 / 资料管理路径

| 入口 | 现状 | 问题 |
|---|---|---|
| 侧栏 | **无**「材料/知识库」 | R2 去干扰后只留今日/助理/课程/卡片/待确认/连接 |
| 命令面板 | **无** library | 同上 |
| 助理 | 链「管理 / 上传材料」→ `/opening/library?tab=materials#upload` | 唯一显眼入口；需先开助理 |
| 课程页 | 「管理知识库」→ 同上 | 有链，但空态文案像「材料可独立存在」，不教如何挂接 |
| Today | 「课程知识 / 材料在课程页」 | 不进材料库整理 |

材料库本身：左栏空间（全部/待整理/就绪/失败/**按课程**）+ 筛选 + Inbox 上传/管理 + **多选后才出现**批量整理条。单份材料无「一键关联课程」。

## ② 关联课程路径（现状）

```text
进入 /opening/library?tab=materials
  → 勾选一份或多份材料
  → 批量条：选择课程 + 用途(参考/核心/拓展) →「归入课程」
  → POST /api/courses/:courseId/memberships
       { assetType:"source", assetId, role, sortOrder:0, visibility:"private" }
  → 行下显示课程标签；左栏「课程名」空间可见
```

移除：材料库（在课程空间）「移除课程引用」或课程页「移出此课程」→ `DELETE .../memberships`。

课程页 **不能新增** 挂接，只能列表 + 移出 + 链回材料库。

## 缺口（为何像「无法正确关联」）

1. **发现性：** 找不到材料库 → 以为没有「资料管理」。  
2. **心智负担：** 必须多选 + 选课 + 用途；失败时只见批量结果红字，易以为「关联坏了」。  
3. **课程页单向：** 在课程里想加材料只能跳走，空态不引导「去材料库勾选归入」。  
4. **organization 未就绪：** `organizationReady`/`organizationError` 时批量禁用；课程列表空则下拉无课可选。  
5. **助理选材料 ≠ 课程挂接：** 助理勾选只影响本轮提问，不写 membership。
