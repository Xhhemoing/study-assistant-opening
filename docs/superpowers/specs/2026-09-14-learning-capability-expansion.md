# 学习管家能力扩展：当前需求补充

状态：2026-09-14 用户明确要求将缺失功能纳入计划，并确认邮箱为学校自建；本文记录该需求变更与实施边界，不代表功能验收或账号访问授权。

本补充优先于原开学版中“自动收邮箱不纳入”“转写可以直接暂缓”的范围限制；原文研究证据不追溯修改。原五项核心功能仍是基础交付，不再等同于满足全部需求。

## 1. 必须覆盖的能力

| ID | 用户目标 | 必须产生的结果 | 任务 |
|---|---|---|---|
| CAP01 | 学校自建邮箱接入 | 经授权读取选定文件夹/时间范围内的通知与附件，增量同步、去重、断线恢复、可撤销 | X01,C01,C02 |
| CAP02 | 钉钉学习数据接入 | 对账号实际允许的通知/文件能力做授权探测、接入及状态展示；无权限不可冒充可读 | C01,C03 |
| CAP03 | 课件、上课视频和录音理解 | 保存原件，提取文档/音轨/关键帧，形成带页码或时间戳的材料；支持纠正和失败重试 | I01,I02,V01 |
| CAP04 | 自动构建知识架构 | 课程章节、概念、先修关系、例题和题型关联；证据可回溯、可纠正、材料更新后增量修订 | K01 |
| CAP05 | 动态跟踪与有针对性的课外辅导 | 将作答、用时、提示及核验依据连接到技能；解释、示例、变式、独立新题、延迟重测形成闭环 | L01,L02,K02 |
| CAP06 | 减少学习生活规划负担 | 将通知、截止、课表、掌握证据和明确可用时间汇总成少量优先行动；只在关键歧义/高影响变化时确认 | P01,P02,P04,U04 |

“全面提高”作为产品目标，不能作为未经个人独立新题、延迟重测验证的成效承诺。未上传不等于没学习，生成知识结构也不等于用户已掌握。

## 2. 默认设计与复用边界

- 邮箱优先 ImapFlow（IMAP客户端）+ MailParser（流式MIME解析），运行在现有worker，不自写协议栈、不自建邮件服务器。
- 学校自建不等于必有IMAP。仅用户配置并授权的主机、端口、TLS、账户可探测；核对学校帮助页/网管说明。没有IMAP则显示阻塞，提供用户导出`.eml`的手工路径；手工导入不算自动接入完成。
- EmailEngine作为可选集成服务：减少账号同步/API封装工作，但现许可证为商业条款，购买/部署需单独批准，不默认引入。
- 钉钉采用官方开放平台能力/SDK适配，不把群机器人推送等同于读取历史群聊；不抓取客户端数据库、不绕过学校或组织管理员授权。
- 文档复用既定Docling路线；视频解码/音轨提取复用FFmpeg；转写优先本地faster-whisper。模型下载、云端转写和真实费用均显式授权。
- 参考DeepTutor的有来源问答与辅导流程；不整套搬入另一套用户、权限、存储和Agent平台。课程知识关系先用现有PostgreSQL，不以新增图数据库为前提。
- 只自行实现本产品必须拥有的编排：数据来源/权限、课程归属、学习证据规则、任务确认、隐私删除和验收。

开源能力、许可证及未验证边界见 [复用核查](../../quality/opening-capability-reuse-research.md)。选型是计划建议；采用前锁定实际发布制品与完整依赖许可。

## 3. 少思考，不等于失去控制

默认每天至多三个优先行动，附预计用时、来源和简短原因；低风险归类自动完成，歧义集中到一张确认卡。
同一通知重复到达不重复问；更正通知生成差异，不能静默覆盖已接受计划。课程、睡眠、吃饭和锁定事项不可侵占；缺课表不当空闲。
未完成任务提供重排建议，不自动标记失败或完成。用户拒绝建议后不立刻换措辞再问。已确认授权范围内可自动同步，不逐封批准。
外发邮件、自动提交作业、写外部日历、删除原邮件和新数据源授权不在默认自动化权限内。

## 4. 隐私与可靠性

邮箱默认只读、不标已读、不删除；正文/附件只进授权workspace。默认只处理用户选择的范围，不扫描全部历史邮箱。
凭据加密、密钥与数据库分离；日志、模型上下文、导出和备份中无明文凭据。撤销立即停止新任务并阻断运行中任务写回；保留/删除已导入材料是独立选择。
不加载HTML远程图片或附件URL；邮件和课件内容属于不可信资料，不得成为工具授权指令。
录音含他人信息时用户需有处理权限；原件、本地转写、向外部模型发送的范围分别可见。

## 5. 交付分层及验收

基础M0–M4可先交付以便使用；新增M5覆盖全部CAP01–06，不得用基础交付替代用户本轮要求。新增功能现在已入计划，不是未排期的愿望清单。

- 先做X01契约和C01授权/隐私基础，再推进邮箱、钉钉、多模态和知识结构；已有安全存储、worker、真实辅导仍是前置。
- 每条链分别报告自动化测试、真实服务、真机及语义效果。钉钉无权限、邮箱不开放协议或设备不足均是明确阻塞；降级可用不抹去原目标。
- Q04是扩展交付门禁：学校邮件/钉钉通知→关联材料→知识结构→独立作答与辅导→重测→次日安排；跨端恢复、撤销、删除和备份恢复必须复测。
- 用户材料之外使用脱敏合成样本；私人邮件、课程录音、账号信息不提交仓库。无账号时只验证本地协议测试，不声称兼容学校服务。
