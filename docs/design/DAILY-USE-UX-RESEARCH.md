# 从日常使用出发的 UI/UX 研究建议

状态：供讨论的设计建议；尚非获批改版合同，也不代表功能已实现。研究记录于 2026-09-20。

用户已选择：专业、简洁的工作台（A）＋温和、尊重的反馈（B）。本轮目标：界面简约、使用自然、功能强大。

## 1. 本轮纠正与依据

- 当前分支应遵循 [9 月开学版批准设计](../superpowers/specs/2026-09-12-opening-release-design.md)，主导航为**今天／助理／课程**；不能因 7 月 PRD 使用 Learn／Explore／Library 就判定新导航错误。
- [9 月能力扩展](../superpowers/specs/2026-09-14-learning-capability-expansion.md)已纳入邮箱、钉钉、音视频、课程知识结构、针对性辅导与规划。它们需要合理入口，不能因界面简化被排除。
- 自由询问、独立笔记、跨课程资产复用继续保留；课程是可选上下文，不能成为写作和交流的前置条件。
- [信息与 AI 政策](../product/UX_AND_AI_POLICY.md)继续约束状态词、原因展开、用户控制和默认信息预算。预算是上限，不要求填满每个卡位。
- 四模型研究、源码核查及公开组件核验见 [证据记录](UIUX-RESEARCH-EVIDENCE.md)；此前未形成正式的用户访谈证据，本轮场景仍需用户实践验证。

## 2. 先定义用户每天要完成的事

| 日常情境 | 最短使用路径 | 应留下的结果与恢复能力 |
|---|---|---|
| 打开应用，不知道先做什么 | 今天 → 继续上次／一项优先行动 | 同一问题、材料页位、草稿和已用提示；没有任务也能直接提问或记录 |
| 上完课收到课件、通知或录音 | 上传或已授权接收 → 仅确认归属歧义 | 原件、来源、处理状态；解析失败仍可读原件；离页后可找回任务 |
| 看不懂一个公式、做题卡住 | 在材料当前页问助理 → 提示／完整解释 | 可点开的来源、纠正识别入口、后续具体问题；看答案不冒充独立掌握 |
| 想随手写想法、做笔记 | 新建笔记 → 直接写；可稍后归课 | 独立笔记、保存状态、撤销与安全副本；不先填目标、标签、课程 |
| 想找以前学过的内容 | 全局搜索／资料与笔记 → 按标题、课程、类型找 | 原件、笔记和对话各自清楚；支持回到材料页／录音时刻 |
| 今天没做完，明天想继续 | 看重排建议 → 看变更 → 接受／保持原计划 | 正式计划新版本，保留休息与锁定事项；不直接宣布失败 |
| 疲惫、想聊聊 | 助理 → 倾听／一起想办法 | 不强迫转成任务；记忆可看、可改、可删；不保存模式有真实链路才开放 |

共通原则：进入即能做事；低风险整理少确认；重要改变可预览；失败不丢劳动；换设备能接着做。

## 3. 推荐导航：三个主入口＋直接可见的资源入口

```text
AIstudy                         搜索  ＋新建
  今天                           ＋：记笔记／上传资料／记一件事
  助理
  课程

  资料与笔记                    不需要课程；全局资产视图
  收件箱 · 2 待确认             新进内容与处理状态
  最近使用／收藏                 只显示少量真实条目

  设置与账户
```

- **今天：**先显示“继续上次”，再显示至多三项优先行动与近期课程／截止摘要；待确认事项集中一处，周视图按需打开。
- **助理：**单一助理和可发现的会话历史；“学习／倾听／一起想办法”切换回应方式，不创建三个隔离机器人。学习内提供“给点提示／完整解释”。
- **课程：**列表进入课程详情；详情一级页签控制在“概览／材料与笔记／学习记录／知识结构”四项。目标与课程时间配置放课程设置；卡片、错题、重测放学习记录内的筛选。
- **资料与笔记：**全局持久资产视图，默认最近使用，可筛笔记、原始资料及课程；独立新建笔记常驻。收藏、标签、批量操作按需出现。
- **收件箱：**处理新进入的材料、归属歧义、同步错误；明确区分待确认／处理中／失败。它不是第二份资料仓库。
- **全局搜索：**能查课程、材料、笔记、对话和具体问题；命令快捷键是加速方式，可见按钮是基础入口。

桌面保留中文文字导航，可主动折叠；移动底栏保留今天／助理／课程。移动顶栏保留“资料”、搜索和新建入口；收件箱在资料页和今天的待确认计数直达，不挤入更多底栏项。

知识库是否升为第四主项留作可逆决策：若实际使用表明独立写作、查资料是主要到访目的，或入口持续找不到，再提升层级并允许设为默认落点。此阶段不得把笔记仅藏在搜索或 AI 对话后。

## 4. 强大功能的四层呈现

| 层 | 原则 | 功能与位置 |
|---|---|---|
| 默认工作面 | 当前要做什么、结果怎样 | 主导航、当前内容、一个主行动、搜索／新建、保存／处理状态、当前上下文 |
| 当前任务工具 | 需要时就在旁边 | 页码／时间戳、引用、提示、完整解释、原因、纠正、保存为笔记、生成候选卡片、重测、计划差异 |
| 管理与组织 | 批量、低频、跨内容 | 课程目标与时间、知识结构编辑、错题／卡片列表、版本、导出、邮箱／钉钉授权范围、同步状态、AI 自动化权限 |
| 开发者诊断 | 供定位问题 | 任务日志、模型／策略版本、证据权重、原始事件、重算；与用户学习页分离 |

记忆查看、纠正、删除和撤销授权是普通用户控制，在助理／设置中直接可见；不能下沉到开发者页。核心操作不能仅在 hover、快捷键或隐含手势中出现。

AI 生成的知识结构默认呈章节／概念列表，点击查看来源和先修关系；图谱是可选视图。不要把关系图、配置表和学习状态都放到课程首屏。

## 5. 三个主要工作面的具体布局

### 今天：帮用户开始和恢复

```text
今天                              ＋新建
继续：高数 · 反函数第 2 步           [继续]
今日行动                         [查看安排]
  12 分钟  检验昨天卡住的一个问题     [开始]
  20 分钟  阅读本周讲义               [开始]
近期：下午有课／一项已确认截止
待确认：两份材料待归类                [查看]
```

示意内容不是用户真实数据。首屏突出一个当前动作，其余是安静的列表；没有证据时不填假进度、不显示掌握百分比、不做打卡惩罚。计划行的“手动完成”与实际学习证据分开。

### 助理：资料、问题与来源在一起

桌面：可折叠全局导航＋材料工作面／对话；宽度随任务调整，默认约 55:45，窄桌面主动切为单面板。不要再叠一个永久三栏管理区。

- 顶部上下文：“数学Ⅰ · 第 3 周讲义 · PDF 第 12 页”，可切换、清除；无材料时显示“自由交流”。
- 点引用定位原文页／音视频时刻；选中段落后“问助理”，保留来源锚点。
- 输入处只保留文本、附件、发送及简洁模式切换；材料选择通过紧凑标签／选择器完成，不常驻全量文件复选列表。
- 发送后立即显示用户消息及真实阶段；任务完成自动更新。停止生成须有后端取消契约，不把停止轮询说成已停止计费。
- 消息可复制、保存为笔记、纠正来源；AI 提议写入正式内容必须经确认。
- 手机以“材料／对话”切换，保留双方滚动位置；软键盘与安全区下输入框可见；公式仅在局部横向滚动。
- 附件仍在上传时，浏览器后台可能中断；只有服务端接收完成后才能说“可以离开，继续处理”。

### 资料与笔记：先好找、好写，再组织

桌面：列表／目录与正文可切换；正文宽度约 760–880px，表格、公式可局部扩展。标题与保存状态清楚，目录、属性、关系、AI 使用一个互斥上下文面板。

- 新笔记无需填写 slug、课程或一组属性；标题可稍后修改。
- 自动保存作为目标行为；状态分为已保存／待同步／失败，冲突时保留本地副本再比较，不用重载覆盖劳动。
- “编辑／阅读／练习”是同一内容的不同用法；练习由用户主动进入，不强制所有笔记卡片化。
- 属性、双链、版本、归档、导出可发现但不抢占正文。移动端打开相应面板，不把五组工具直接堆到文末。
- 自由探索可从助理发起；值得保存的内容进入笔记，开放问题与分支保留为结构化探索，不只剩聊天记录。

## 6. 视觉方向：清楚、舒适、克制

Primary 参考 Linear 的导航与列表结构；不复制其过小密度、默认深色或品牌色。写作面参考成熟块编辑器的阅读规律。

| 项 | 建议约束 |
|---|---|
| 明暗 | 跟随系统，允许浅／深色手动选择；全部路由与编辑器使用同一偏好。A/B 选择并不意味着用户已批准浅色默认 |
| 色彩 | 中性背景＋沿用品牌蓝的语义强调色；浅色与深色各自校准对比度，不直接复用同一前景值 |
| 字体 | 系统中文无衬线栈；正文 15–17px、行高 1.6–1.8；导航 14px 左右，辅助文字通常不低于 13px |
| 层级 | 页面标题约 22–28px；靠字重、位置、留白组织，不依靠每段一个彩色卡片 |
| 密度 | 4／8px 间距节奏；导航约 224–240px，列表以舒适密度为默认，正文保留阅读宽度 |
| 控件 | 常用操作约 40–44px，触控目标建议至少 44px；单一焦点系统，禁用、选中、错误都可辨认 |
| 圆角与阴影 | 控件 6–8px、浮层 10–12px；阴影主要服务浮层关系，内容列表用间距和分隔线 |
| 动效 | 120–200ms 的状态变化；支持减少动态效果，不人为延迟结果以展示动画 |
| 温和反馈 | “问题已保留，可以重试”“今天先到这里”“保持原计划”；不使用负罪感或虚假紧迫文案 |

正文对比度目标至少 4.5:1；控件关键边界／焦点按至少 3:1 校验。状态不能只靠颜色；中文输入法组词期间 Enter 不发送。

## 7. 性能与功能完整性共同设计

已见风险包括：认证和内容加载瀑布、重复认证请求、编辑时全量草稿序列化、素材列表全量渲染、任务只刷新一次。当前开发服务存在构建错误，尚无可用的渲染基线，详见证据。

- 认证结果由可信服务端／共享上下文复用；不为了快绕过鉴权。独立请求并行，尽快展示可用区域。
- 助理按 jobId 订阅或有界轮询，处理卸载取消与重连；后台任务时长、网络等待、主线程渲染分别测量。
- 数据缓存按用户／工作区及资源标识隔离；接受计划、删除、撤销授权等操作后正确失效。
- BlockNote、阅读器、图谱、视频播放器与高级面板按路由／打开时加载；并非所有 client component 都需要 SSR 重写。
- 草稿高频编辑与低频管理面板隔离，合并持久化写入并保证可靠刷新；防抖不能扩大无法恢复的数据窗口。
- 长列表先分页；长对话虚拟化须先验证动态消息高度、引用定位、文本选择和读屏体验。

建议验收：有效页面上的 LCP≤2.5s、INP≤200ms、CLS≤0.1 作为待测目标；固定设备／网络／生产构建条件，记录样本与 p75。单次本地 dev HTTP 耗时不等于这些指标，也不等于 AI 完成时间。

## 8. 推荐落地顺序与验收

1. **可运行与可靠交互基础：**定位当前构建阻断，修正跨壳课程跳转与主题语义，建立性能基线；笔记冲突保留本地副本。每个修复有同检查复验。
2. **材料到次日继续：**上传／已授权接收 → 来源与处理状态 → 当前页提问 → 可点击引用 → 具体学习问题 → 另一设备继续。穿插统一壳与基础组件，不单独交一张新皮肤。
3. **无课程也能使用：**直接交流／新建笔记 → 保存与搜索 → 版本冲突恢复 → 自愿沉淀；倾听／不保存只有在相应服务端契约和删除验证完成后开放。
4. **主动学习管家：**通知 → 去重归课 → 可追溯知识结构 → 独立新题／重测 → 今日少量行动 → 计划变更确认。邮箱／钉钉、视频／录音均保留在批准范围内；手工导入不能冒充自动接入完成。

验收必须用完整任务：空账号、长中文内容、桌面1440×900与手机390×844、中文输入法、断网、解析失败、模型失败、跨端恢复、版本冲突和键盘操作。浏览器截图只能证明可见状态；实际学校授权、AI语义与手机后台行为须分别验证。

## 9. 仍适合与你讨论的两个取舍

- “资料与笔记”先作为固定资源入口，还是你的日常记录频率已经足够高，值得立刻成为第四主导航？当前推荐前者，但不能隐藏。
- 第一个画面是否以“继续上次”为核心，而不是每次打开都推一份计划？当前推荐继续上次优先，今天仅提供少量可选下一步。
